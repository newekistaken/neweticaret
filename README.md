# E-Ticaret Vize Sınavı Test Portalı

Bu proje, 100 soruluk **E-Ticaret Vize Sınavı Hazırlık Testi** için modern, duyarlı (responsive) ve anlık açıklamalı web uygulamasıdır.

## 🚀 Özellikler
- **100 Özgün Soru:** Choi modeli, e-iş vs e-ticaret, mobil teknolojiler, protokoller (HTTP, FTP, SMTP, POP, EDI), kablosuz iletişim (Bluetooth, Wi-Fi, 3G) vb.
- **Anlık Geri Bildirim & Açıklama:** Şık tıklandığında anında doğru/yanlış durumu ve konunun ayrıntılı açıklaması.
- **Klavye Desteği:** `A`, `B`, `C`, `D` şık seçimi, `←` / `→` soru geçişleri, `Delete` temizleme.
- **Otomatik Kayıt (LocalStorage):** Sayfa yenilense bile çözümleriniz kaybolmaz.
- **Karanlık / Aydınlık Tema (Dark Mode):** Göz yormayan şık arayüz tasarımı.
- **Sentetik Ses Efektleri:** Harici dosya gerektirmeyen Web Audio API ile doğru/yanlış sesli geri bildirimi.
- **Soru Haritası ve Filtre:** Yanlış yapılan veya boş soruları filtreleyerek hızlıca geri dönme imkanı.
- **Kapsamlı Sonuç Raporu:** Doğru, Yanlış, Boş, 4 Yanlış 1 Doğru Net Puanı, Başarı Yüzdesi ve filtreli soru inceleme alanı.
- **Yazdır / PDF:** Sınav sonucunu tek tıkla yazdırma veya PDF olarak kaydetme.

## 🌐 GitHub Pages ile Canlıya Alma (2 Dakikada)

Bu projeyi GitHub üzerinden canlıya almak için aşağıdaki adımları izleyebilirsiniz:

1. **GitHub'da Yeni Repo Oluşturun:**
   - [github.com](https://github.com) adresine gidin.
   - Sağ üstteki **+** simgesinden **New repository** seçeneğine tıklayın.
   - Repository name olarak örneğin `e-ticaret-vize-testi` yazın.
   - **Public** seçili olsun ve **Create repository** butonuna basın.

2. **Dosyaları Yükleyin:**
   - Açılan sayfada **"uploading an existing file"** linkine tıklayın.
   - Bu klasör içindeki `index.html` ve `README.md` dosyalarını sürükleyip GitHub yükleme alanına bırakın.
   - Aşağıdaki **Commit changes** butonuna tıklayın.

3. **GitHub Pages'i Aktif Edin:**
   - Reponuzun üst menüsünden **Settings** sekmesine gelin.
   - Sol taraftaki menüden **Pages** seçeneğine tıklayın.
   - **Build and deployment** başlığı altındaki **Branch** kısmında:
     - Branch olarak `main` seçin.
     - Klasör olarak `/ (root)` seçin.
     - **Save** butonuna tıklayın.

4. **Tebrikler!**
   - 1-2 dakika içinde GitHub size `https://<kullanici-adiniz>.github.io/e-ticaret-vize-testi/` şeklinde canlı web linkinizi verecektir.
